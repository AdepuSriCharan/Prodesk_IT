# Sprint 01 - Prodesk IT Landing Page

Responsive landing page for a fictional digital marketing agency.

## Features

- Tailwind CSS based responsive layout
- Sticky glassmorphism navbar
- Dark mode toggle with `localStorage` persistence
- Micro-interactions on buttons and service cards
- Mobile and desktop compatible sections

## Files

- `index.html` - page structure
- `styles.css` - custom styling and interactions
- `script.js` - dark mode + mobile menu behavior
- `Prompts.md` - AI prompts used
- `assets/` - image assets
- `screenshorts/` - submission screenshots
